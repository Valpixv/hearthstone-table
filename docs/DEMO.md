# 90-second demo script

**Setup (before recording):** run `npm run dev:http`. Open two browser windows at `http://localhost:5174`: one for the Dungeon Master, one for a player. No headset is needed; every beat also works in VR.

| Time | Who | Action | What to say |
|---|---|---|---|
| 0:00 | DM | Home screen → **Host table**. The dock opens on the Table tab with the code and QR. | "This is Hearthstone Table: a D&D table you sit at in VR. The Dungeon Master hosts and gets a code." |
| 0:08 | Player | **Join table**, type the code and a name. The character builder opens. | "Players join with the code and build their character first, on a desktop." |
| 0:15 | Player | Pick a class, click through to Abilities, **Roll**, then **Quick build** and **I'm ready**. | "All twelve classes, rolled scores or standard array, and a full 2024-style sheet behind it." |
| 0:28 | DM | The roster shows the player ready. Press **Begin the adventure**. | "When everyone is ready the DM begins, and players put their headsets on. Their character follows them." |
| 0:36 | DM | Creatures tab → drag a **Goblin** tile onto the room. Then drag the life-size goblin somewhere else. | "The DM pulls creatures out of the gallery and stands them life-size around the table." |
| 0:48 | DM | **Call for a roll** → the player → Damage → target the goblin → **Ask**. | "The DM calls for a roll." |
| 0:55 | Player | Press **Roll** on the prompt (or throw the dice). | "The player throws real dice." |
| 1:02 | DM | The confirm card shows the total. Press **Confirm**. | "The DM confirms what it does. Nothing has happened to the goblin yet." |
| 1:08 | Player | The banner says *Unleash it*. Press **Enter** (in VR: make the hand sign at the goblin). | "And the player's hand sign delivers it: the effect flies, and the damage lands when it hits." |
| 1:18 | DM | World tab → **Crypt**, then **Rain**. | "The DM changes the world around the table: scenes, weather, music, narration." |
| 1:26 | Both | Click **Mic** in both windows. | "Voice chat comes from each player's seat. All that is left is to put the headset on." |

**Fallbacks:** *Test mode* on the home screen skips the code and the character stage. If the dice pile up, press `C`.
